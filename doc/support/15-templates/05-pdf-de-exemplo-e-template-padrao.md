# PDF de exemplo e template padrão

Antes de usar um template com clientes, confira como ele fica no PDF real com uma proposta de exemplo. E escolha qual
template é o **padrão** da empresa, usado sempre que um orçamento não tem um template escolhido.

> **Disponível em:** planos Essencial, Profissional, Prime e Master · **Quem pode usar:** todos os usuários

## Ver a pré-visualização na tela

Depois que o template é salvo pela primeira vez, o fim da página de edição mostra a
**Pré-visualização com a proposta de exemplo**: as páginas de capa, conteúdo e contracapa (só as que estiverem
incluídas), com a mesma aparência do PDF.

A pré-visualização usa a **última versão salva**. Depois de mudar algo, clique em **Salvar** para atualizá-la.

## Gerar o PDF de exemplo

1. No menu lateral, clique em **Templates** e abra o template.
2. No topo, clique em **PDF de exemplo**.
3. O PDF abre numa nova aba, com dados fictícios de evento, cardápio e valores.

Se houver alterações ainda não salvas, o sistema pergunta **Gerar o exemplo sem salvar?**:
- **Voltar e salvar**: volta para a edição, para você salvar antes;
- **Gerar mesmo assim**: gera o PDF com a última versão salva (sem as alterações atuais).

## Definir o template padrão

1. Abra o template que deve ser o padrão.
2. No topo, ligue **Template padrão das novas propostas**.
3. Clique em **Salvar**.

O template anterior deixa de ser o padrão automaticamente. Na lista de **Templates**, o padrão aparece primeiro, com
a marca **Padrão**.

## Regras do template padrão

- Sempre existe um template padrão. O primeiro template da empresa já nasce como padrão.
- Não dá para desmarcar o padrão diretamente: marque outro template como padrão.
- O template padrão não pode ser excluído enquanto for o padrão.
- Orçamentos sem template escolhido usam o padrão. Se você trocar o padrão, os próximos PDFs desses orçamentos saem
  com o novo visual.
- Uma cópia feita com **Duplicar** nunca nasce como padrão.

## Perguntas frequentes

### O PDF de exemplo usa os dados de um evento real?
Não. Ele usa uma proposta fictícia, só para conferir o visual.

### Mudei o padrão. As propostas já enviadas mudam?
Não. Os PDFs já gerados continuam como estavam.

### Posso usar um template diferente do padrão em um evento?
Sim. Escolha o template no orçamento do evento. Veja
[Escolher o template da proposta](../04-orcamento/10-escolher-template-da-proposta.md).
