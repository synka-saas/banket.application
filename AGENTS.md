# Banket - Sistema de gestão para Buffets

O sistema se trada de um Saas que vamos oferecer aos nossos clientes para gerenciarem seus buffets. As funcionalidades principais consistem em gerenciar o envio de propostas comerciais, cardápios, agendamento de eventos e gestão de equipe.


## Development

Está sendo usado Astro SSR com banco de dados postgre. Tudo sendo orquestrado por containers (Docker).
