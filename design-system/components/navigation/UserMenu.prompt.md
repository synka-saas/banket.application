Header account button — avatar, name, role, chevron; opens a Menu when `items` is set.

```jsx
<UserMenu name="Leandro" role="Proprietário" items={[
  { label: "Meu perfil", icon: "user" },
  { label: "Configurações", icon: "settings" },
  { divider: true },
  { label: "Sair", icon: "logout", danger: true },
]} />
```
