Label ↔ value rows (definition list) — inside kanban event cards, menu-option cards, form cards.

```jsx
<InfoList size="sm" items={[
  { label: "Pessoas", value: "50" },
  { label: "Formato de serviço", value: "Serviço volante" },
  { label: "Orçamento", value: "R$ 9.250,00" },
  { label: "Data", value: "29/10/2026" },
]} />
```
