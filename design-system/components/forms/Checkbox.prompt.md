Checkbox for independent yes/no options inside a list — "Obrigatória" on form questions, multi-select filters, bulk row selection.

```jsx
<Checkbox label="Obrigatória" size="sm" defaultChecked />
<Checkbox label="Incluir bebidas" />
<Checkbox indeterminate label="Selecionar todos" />
```

- Use `Switch` instead when the change applies immediately (ativar/desativar).
